Практическая работа №8.

Задание: Разработать консольную программу на C# для подсчета результатов турнира между 3 волшебными школами, в каждой из которых участвует одинаковое количество человек ($N$, вводится пользователем). Баллы участников рассчитываются по формуле $i \times 10 + j \times 3$ (где $i$ — номер школы, $j$ — номер участника), после чего программа должна вывести индивидуальные результаты, общую сумму баллов каждой школы, а также определить школу-победителя и лучшего участника турнира.
